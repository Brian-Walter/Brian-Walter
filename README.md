### Stealth AI Game

A Unity project focused on NPC behavior systems and real-time AI decision logic.

#### Demo

![Stealth AI Demo](https://raw.githubusercontent.com/Brian-Walter/Stealth-3D/main/Documentação/demo.gif)

#### Features

- Raycast line-of-sight validation

- Separation between perception, decision, and movement systems  

#### Technologies

- Unity  
- C#  
- AI for Games  
- State Machines  
- Navigation Systems
