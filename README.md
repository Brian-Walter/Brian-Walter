## Projetos em destaque

### WA Transport
Site full-stack em produção para uma empresa de transporte executivo, com landing page, sistema de reservas, painel administrativo autenticado e políticas de Row Level Security no banco.

`Next.js` `TypeScript` `Prisma` `Supabase` `NextAuth`

[Repositório](https://github.com/Brian-Walter/wa-transport) · [Site em produção](https://www.watransport.com.br/)

### TrocaTicket
Projeto Interdisciplinar da FECAP: plataforma de planejamento e precificação de eventos com módulos para Organizador, Fornecedor e Administrador. Em desenvolvimento.

`Node.js` `Express` `MySQL` `React`

[Repositório](https://github.com/2026-2-MCC2/Projeto8)

### EcoCity
Jogo de tabuleiro 3D inspirado em Monopoly, desenvolvido em Unity, com mecânicas sistêmicas de dinheiro, bem-estar e poluição.

`Unity` `C#`

[Jogar no Itch.io](https://brianwalter-q.itch.io/ecocity) · [Repositório](https://github.com/2026-1-MCC1/Projeto10)

`Unity` `C#` `AI para Games`
